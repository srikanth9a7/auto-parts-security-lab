SECURITY DESIGN

Three controls, one clear purpose.

1 / Bind query values

Use WHERE order_code = ? rather than building SQL with user text.

2 / Do not render input as HTML

The receipt inserts untrusted data through textContent, not innerHTML.

3 / Restrict script execution

The browser receives a restrictive CSP as an additional protective layer.
